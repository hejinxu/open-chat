欢迎访问示例网站

这是一个演示页面，展示 Open Chat 嵌入式组件的实际效果。

浮动聊天按钮应出现在页面右下角，点击可打开对话窗口，拖动图标可重新定位。

嵌入配置

window.openChatConfig = {
  baseUrl: 'http://localhost:3000',
  apiKey: 'REPLACE_WITH_YOUR_API_KEY',
  iconUrl: 'https://api.dicebear.com/9.x/bottts/svg?seed=openchat',
  windowTitle: 'AI Assistant',
  theme: 'tech-blue',
  windowSize: {
    width: 420,
    height: 640,
    minWidth: 320,
    minHeight: 400,
    maxWidth: 800,
    maxHeight: 900,
  },
  headerStyle: {
    backgroundColor: '#1C64F2',
    textColor: '#ffffff',
    iconColor: '#ffffff',
    buttonHoverBg: 'rgba(255,255,255,0.15)',
  },
}
配置说明：将 REPLACE_WITH_YOUR_API_KEY 替换为管理面板生成的 API Key。
内置图标（14 个）：robot · bot · chat · sparkle · headset · message · brain · wand · rocket · puzzle · eye · code · gear。 设置 icon: 'chat' 切换图标，或使用 iconUrl 指定自定义图片。

功能测试

使用此页面验证以下嵌入功能：

  • 浮动按钮：应出现在右下角，显示机器人图标
  • 拖拽：点击并拖拽按钮可重新定位
  • 打开：点击按钮（非拖拽）打开对话窗口
  • 窗口拖拽：拖拽标题栏可移动窗口
  • 调整大小：拖拽右下角手柄可调整窗口大小
  • 关闭：点击 × 按钮关闭窗口，恢复浮动图标
  • 移动端：使用 DevTools 设备模拟测试全屏模式
  • 指令：点击下方"注册监听"，然后在对话中发送指令

指令测试

测试 AI 指令解析与宿主通信（HTML 注释嵌入方案）：

  1. 点击注册监听开始监听来自对话 iframe 的指令
  2. 在对话窗口中发送触发 AI 返回指令的消息
    示例提示词："请帮我打开百度"
  3. 当 AI 回复中包含 <!-- COMMAND:{...} --> 时，指令将被解析并显示在下方，同时打开弹窗
